# Телефон ↔ проект

Цель: человек держит телефон, на нём открыто его приложение, правка в коде видна через секунду. Веди по шагам и после каждого жди подтверждения.

Скрипт: `${CLAUDE_PLUGIN_ROOT}/scripts/connect-device.mjs` (если переменная не подставилась — папка на два уровня выше «Base directory for this skill»).

Компьютер ещё не настроен (нет Node, нет входа в Expo) → сначала `expo-pack:expo-setup`.

## Шаг 1. Проверка на компьютере

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/connect-device.mjs" <папка проекта>
```

Проверяет: Expo-проект, зависимости, вход в Expo, Wi-Fi, VPN, занят ли порт 8081. Исправляй ❌:

- **Зависимости не установлены** → `npm install` (запусти сам).
- **Не выполнен вход в Expo** → логин и пароль вводит только человек. Не проси пароль в чате и не подставляй его в команды:
  > Набери в чате `! eas login` (или `! npx expo login`) и введи логин и пароль от expo.dev.

## Шаг 2. Телефон

Спроси, какой телефон, и дай один список.

**iPhone**
1. App Store → установи **Expo Go**.
2. Открой Expo Go → **Log in** → аккаунт, который показал скрипт.
3. Подключись к **тому же Wi-Fi**, что и компьютер. VPN выключи.
4. Expo Go спросит доступ к **локальной сети** → «Разрешить». Нажал «Запретить» → Настройки → Конфиденциальность и безопасность → Локальная сеть → включи Expo Go.

**Android**
1. Google Play → установи **Expo Go**.
2. Открой Expo Go → **Log in** → тот же аккаунт.
3. Тот же Wi-Fi, VPN выключен.

Аккаунты Apple Developer ($99) и Google Play ($25) для Expo Go **не нужны** — только для публикации.

## Шаг 3. Запуск

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/connect-device.mjs" <папка проекта> --start
```

На macOS откроется отдельное окно Терминала с `npx expo start` и QR-кодом. Сервер живёт, пока окно открыто. Без Wi-Fi или с VPN скрипт сам выберет туннель, принудительно — `--tunnel`. Порт 8081 занят → второй сервер не запускается: значит, окно с QR уже есть.

Не macOS → попроси человека запустить `npx expo start` в отдельном окне терминала. Не через `!`: команда не завершается и займёт чат.

Открыть приложение:
- **Самый простой путь:** Expo Go → Home → «Development servers» → нажать на проект. Работает, когда аккаунт и сеть совпадают.
- **iPhone:** обычная камера → навести на QR → «Открыть в Expo Go».
- **Android:** Expo Go → «Scan QR code».

Ожидаемо: полоска «Downloading JavaScript bundle», затем экран приложения.

## Шаг 4. Проверка живой связи

Попроси человека поменять текст на главном экране и сохранить. Через 1–2 секунды текст меняется на телефоне — готово 🎉 Скажи, что теперь так и работаем: окно с `expo start` открыто, правки видны сразу.

## Если не получилось

| Симптом | Действие |
|---|---|
| Проекта нет в «Development servers» | Разные аккаунты или разные сети → сканируй QR |
| QR открывается, загрузка вечная / `Could not connect` | iPhone: включи «Локальная сеть» для Expo Go. Разные сети, гостевой или офисный Wi-Fi → закрой окно expo start и `--start --tunnel` |
| `Project is incompatible with this version of Expo Go` | Обнови Expo Go. Не помогло — `expo:expo-upgrade` |
| `Cannot find native module` | Библиотеке нужна dev-сборка → `expo-pack:expo-run-on-phone` |
| Туннель: ошибка ngrok | Подожди минуту и повтори. Офисная сеть блокирует → раздай интернет с телефона |

Остальные ошибки → `expo-pack:expo-run-on-phone`.
