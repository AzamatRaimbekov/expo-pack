# Настройка Expo с нуля

Цель: за один заход пройти путь от «на компьютере ничего нет» до «моё приложение открыто на телефоне». Веди по этапам. Пропускай то, что уже готово. В конце каждого этапа коротко скажи, что сделано.

Скрипты лежат в `${CLAUDE_PLUGIN_ROOT}/scripts/` (если переменная не подставилась — папка на два уровня выше «Base directory for this skill»).

## Правила

- **Ставит агент, вводит секреты человек.** Команды установки запускай сам. Логин и пароль человек вводит сам через `! команда`. Никогда не проси пароль в чате.
- Перед установкой скажи одной строкой, что ставишь и зачем.
- `sudo` и глобальные изменения системы — только после «да» человека. Установщик Node с nodejs.org человек запускает сам.
- Один этап — одна проверка. Не идёшь дальше, пока скрипт показывает ❌.

## Этап 1. Компьютер

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/setup-check.mjs"
```

Скрипт проверяет: версию Node под требования Expo, npm, git, EAS CLI, вход в Expo, Wi-Fi и VPN. Xcode, Android Studio и watchman помечены как ℹ️ — для Expo Go они **не нужны**, не ставь их без просьбы.

| ❌ / ⚠️ | Что сделать |
|---|---|
| Node нет или старый | Человек скачивает LTS с https://nodejs.org и ставит, потом открывает **новое** окно терминала. Если есть nvm: `nvm install --lts` (можешь запустить сам) |
| `command not found: node` сразу после установки | Терминал открыт до установки → закрыть и открыть заново |
| git нет (macOS) | `xcode-select --install` → человек нажимает «Установить» в окне |
| EAS CLI нет | `npm install -g eas-cli` (запусти сам). Ошибка `EACCES` → не используй sudo, предложи nvm |

> Сам скрипт запускается через `node`. Если `node` не найден, скрипт не запустится — сразу переходи к установке Node.

## Этап 2. Аккаунт Expo

1. Нет аккаунта → человек регистрируется на https://expo.dev/signup (бесплатно) и подтверждает почту.
2. Вход: попроси человека набрать в чате `! eas login` и ввести логин и пароль.
3. Проверь ещё раз `setup-check.mjs` — должно быть `✅ Вход в аккаунт Expo: <логин>`.

Зачем аккаунт: тот же логин в Expo Go на телефоне — и проект сам появится в списке, без QR. Ещё он нужен для сборок APK и публикации.

## Этап 3. Проект

Есть готовый проект → перейди в его папку и `npm install`. Нет → создай рядом с человеком (спроси имя, латиницей):

```bash
npx create-expo-app@latest <имя>
cd <имя>
```

Затем проверка проекта: `node "${CLAUDE_PLUGIN_ROOT}/scripts/expo-check.mjs" .`. Предупреждения про `android.package` и `eas.json` сейчас не мешают — они важны к релизу, просто назови их.

## Этап 4. Телефон

Переходи в `expo-pack:expo-connect`. Там вход в Expo Go, сеть, разрешения iPhone, запуск `expo start` в отдельном окне и проверка живой связи.

## Финал

Когда текст на телефоне поменялся после сохранения, подведи итог человеку:

```
✅ Node, npm, git, EAS CLI
✅ Аккаунт Expo: <логин> (на компьютере и в Expo Go)
✅ Проект: <папка>
✅ Телефон: <iPhone/Android> подключён, правки видны сразу

Каждый день: открой папку проекта → npx expo start → открой проект в Expo Go.
```

Дальше по задачам — `expo-pack:expo`.
